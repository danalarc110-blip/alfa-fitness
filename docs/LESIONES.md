# Información de seguridad y responsabilidad por lesiones

Versión: 2026-10-05-academico. Plantilla educativa de un proyecto estudiantil.

Este texto simula información de seguridad de un gimnasio; no exige asesoría jurídica para la presentación académica. Las rutinas y cargas de prueba no son recomendaciones para entrenar. Si se utiliza para actividades reales, deberá adaptarse a los procedimientos y responsables del gimnasio.

La actividad física y el uso de pesas o máquinas pueden producir fatiga, caídas, lesiones musculares u otros daños. Conocer estos riesgos ayuda a entrenar con cuidado; no elimina la obligación del gimnasio de mantener equipos adecuados, dar instrucciones y cumplir sus deberes de seguridad.

Pide ayuda antes de usar una máquina desconocida. Respeta la técnica, las instrucciones y los límites de carga adecuados para ti. No intentes superar un récord solo porque el sistema muestre una clasificación o una puntuación. Las etiquetas y estadísticas describen registros, no tu aptitud médica ni una carga segura.

Detén el ejercicio y avisa al personal ante dolor, mareo o una situación que te preocupe. Si tienes dudas sobre si una actividad es apropiada para ti, consulta a un profesional de salud antes de realizarla. El gimnasio y la aplicación no sustituyen una evaluación médica ni prestan atención de emergencia por este portal.

Puedes informar al personal que necesitas adaptar una actividad sin escribir diagnósticos, medicamentos o antecedentes íntimos en las notas de la aplicación. Si se necesita recopilar información de salud, el gimnasio debe utilizar un canal restringido y una autorización específica; la aceptación general del registro no autoriza ese tratamiento.

La lectura y aceptación de este aviso expresa que recibiste información sobre riesgos y uso responsable. No supone renunciar a reclamar, aceptar conductas negligentes ni liberar al gimnasio de responsabilidades impuestas por la ley. Para menores o personas que requieran representación, debe aplicarse el procedimiento y las autorizaciones que correspondan antes del entrenamiento.
